# 样机申请流程

从官网“联系我们”打开“样机借用 / 点此申请”。无需注册案例账号。填写主体、联系人、收货信息、型号与期望天数，阅读协议与重点事项；首次提交后核对信息，再点击“确认同意并提交申请”。提交不代表获批；具体借期与设备由工作人员批复。

## 提交前请确认

查看完整借用协议

提交即表示同意《RM-01 产品借用协议》及以下重点事项

- **押金及汇款** 人民币30,000元或按确认邮件固定报价折算的等值美元，确认邮件送达后24小时内汇出，足额到账并完成主体与授权核验后发货
- **往返运费及保价** **厂家寄出：运费到付，由厂家足额保价；你寄回：自付运费及保价费，并按协议整机价值足额保价** ，往返运费及保价费均由申请人承担
- **归还及延期** 借期包含往返运输，到期前机器及全部配件须实际送达厂家；延期须提前七个自然日申请，七天及以内借期不接受延期，未获批准仍按原截止时间归还
- **逾期与赔偿** 整机价值由管理员审批时填写，逾期归还和赔偿款逾期支付均按整机价值每日1%计费，同一期间不叠加；乙方责任损坏、缺件或丢失优先结算押金，不足补足
- **断电操作** 磁吸盖板下三个指定接口仅可断电插拔，存储卡以可见序列号登记；带电插拔损坏须承担全新同型号卡费用，无法采购时按协议使用同等技术规格的国际知名品牌替代
- **账户信息恢复** **如修改过样机默认账户信息或密码，归还前必须恢复至交付记录所载的初始状态，确保原默认账户及密码可正常登录**
- **邮件知悉及退款** 协议邮件送达后48小时内回邮知悉，未回复依事先约定视为知悉，已知退信不计时；正常归还后五个工作日内退款，人民币退人民币、美元退美元，有应结款项按协议处理

同意协议并继续

提交将保存申请、条款版本、重点提示和确认行为，用于借用办理与追溯；个人信息处理方式、保存期限及权利渠道见完整协议
