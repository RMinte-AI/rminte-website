# 网页改动复审 · 2026-10-30

本轮仅复审指南页 Agent 入口的 i18n、复制弹窗与手机布局。修复两处 P2 交互问题；产品代码仅修改 `website/assets/knowledge-entry.js` 和指南入口 HTML 中该脚本的缓存版本。没有修改 MCP、译文或布局，没有提交或部署。

## 已修复

1. **旧复制结果写入重开的弹窗。** 在中文窗口发起复制、尚未完成时关闭，切换英文后重开，旧请求完成会在英文窗口显示“已复制”，而完成的是上一次中文请求。原实现的 await 回调直接更新共享状态节点，没有区分窗口的打开批次。现在结果只更新其所属且仍打开的窗口；复制操作仍按原逻辑串行，不新增重试或替代复制方式。
2. **拖选指令到窗外松开会误关闭。** 原实现只判断最终 click 的目标与坐标，浏览器可将跨边界拖选生成的 click 派发到 dialog。现在要求手势起点和终点都在遮罩上才关闭；指令内起始的拖选保持窗口打开，普通遮罩点击与触控关闭仍有效。

- 使用真实浏览器鼠标拖选并在窗外释放，修复前误关、修复后保持打开。普通遮罩点击、触控点击、Escape、关闭按钮及焦点/滚动恢复通过。
