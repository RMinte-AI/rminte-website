## 确认并修正的缺陷

| 问题 | 触发条件与后果 | 根因修正 |
| --- | --- | --- |
| 原型属性误作索引 | 查询 `constructor`，返回内部错误而不是无结果；构建遇到同名词也会误取构造函数 | 构建索引用无原型字典；查询仅取自有词项 |
| 协议缩写被当复数 | `HTTPS` 被截成 `HTTP`，混淆两种协议的搜索依据 | 删除无依据的通用去尾 s 规则，保留原始协议词 |
| 同义词改写英文单词片段 | `contraction`、`contractor` 会被展开为借用合同词汇 | 英文同义词只匹配完整单词；不增加这些词的特殊排除名单 |
| 中文停用词删掉有效内容 | `所有权` 等词被删到不剩有效索引，`有线网络` 被改成其他片段 | 分词后按完整词过滤；保留连续单字形成的有效字组，不跨完整词拼造查询词 |
| 上下文按标题文字/层级下标猜测 | 缺少一级标题、跳级标题或同名分支时，父级条件可能丢失/串错；超过 3000 字符的父级正文还会被静默略掉 | 解析时保存真实父节点，完整继承其正文；沿用现有总大小检查，超限明确要求整理源边界，不省略条件 |
| 去重忽略前提 | 两段正文相同但前置条件或版本不同，只留下一个结果 | 去重同时考虑正文、上下文、语言、版本和适用范围 |
| 代码块围栏识别不完整 | 波浪号围栏或四反引号内的 Markdown 标题被错误切分，块可能被拆断 | 两处解析统一按围栏字符、长度和有效结束行处理；不闭合时构建报错 |
| 人工栏目标签占正文结果 | 人工生成的 preamble 复用整篇标题，被当作答案段落，排挤真实参数章节 | 保留原始标签供溯源，禁止其独立参与搜索，不删除原始文字 |

以上改动限于 `src/text.ts`、`src/knowledge.ts`、`scripts/build.ts` 及必要回归检查。没有增加重试链、备用检索器、逐题回答规则、异常吞错或新依赖。
