## 实现

独立 [服务目录](../../services/official-knowledge-mcp/README.md)包含 TypeScript Worker、语料构建、中英文全文索引、两个只读 MCP 工具及验证脚本。仅有 `/mcp`、`/health` 运行路径，官网未修改，`/connect` 留待后续接入阶段。无模型请求，无客户端扩展，无数据库或云存储绑定。

语料库存 88 个条目均被构建报告解释：2 个 OCR 排除且无法读取，2 个历史介绍仅参与显式历史查询，其他按对应资料类型索引。共 1278 个含导航标题的源章节，运行数据 2874170 字节。原文重复正文保留，搜索按章节哈希去重。无正文标题保留供溯源，不单独参与搜索评分。

每次返回包括适用版本、资料性质、原始 URL、原页/行、源提交、采集日期、已知发布日期、语料版本、正文与上下文哈希。未知发布日期为 null，不用采集日期冒充发布日期。

最终语料版本：`35805af01950d5458ac02c864bc8310665586abd1f932ac19cd5e63412a1634d`。

## 与架构草案的具体收敛

1. 中文使用 Intl.Segmenter 分词，再对词内生成二元组；避免跨虚词形成没有实际意义的索引词。数值与单位分开检索；原文数值保持不变。
2. 搜索使用低权重继承上下文，避免大段说明淹没硬件正文。借用、合同、协议等少量同义表达来自已收集资料，不编写逐题答案。
3. 本地不实现 `/connect` 或官网文本框，也未声称四种 Agent 应用已经兼容。这属于本次明确目标之外的后续阶段。
4. 使用当前可安装的官方配套 SDK，而不是按文档中的示例依赖猜测；实际协议头单独验证。

## 未验证和限制

- 证据是本地 Worker 加真实协议客户端，不是生产、云端 CPU 或真实设备证据。未证明免费档 CPU 预算、域名、并发容量、长时运行或生产稳定性。
- 没有验证 Pi、Hermes、OpenClaw、DeepSeek Harness 的配置、重启和实际模型工具使用；没有安装真实客户端扩展。服务返回原文与限制，最终 Agent 的回答/翻译质量未测。
- 88 个问题集和完整性测试不能证明所有自然语言问题都能命中。全文检索存在同义表达与隐含问题漏检的可能；后续新失败应单独保留，不能暗改本轮证据。
- 实时状态只给快照说明及官方核对来源。完整协议只有中文官方原文，英文说明指向中文相关章节。OCR、媒体报道与证书未逐项核验。
- 当前机器 Node 24.10 对部分上游可选 Babel 工具链出现 engine 警告；已测路径均通过。建议后续用 Node 22.18+ 或 24.11+ 复现。未在多个 Node 版本重复验证。
- SDK 开发依赖、正式 Origin/Host 策略及平台日志配置需要在后续发布审查时复核；本地 Host/Origin 限制目前只允许 localhost/127.0.0.1。

本地目标完成不代表可直接发布。下一阶段如获授权，应先确定客户端验证与测试部署边界，再取得云端证据，最后才考虑官网入口。
