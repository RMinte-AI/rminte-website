# AI 数字收费员演示

基于 ChatRaw 52111 的对话主界面、智能体广场和常用项结构，提供独立的中文前端演示。所有数字、记录、车辆编号和资料都是专门编写的模拟数据，不从客户环境复制业务数据、商标、图片或凭据。

## 用户流程

- 新对话：从输入框底部选择四个预设场景之一，发送后查看日汇总、支付结构、异常核对或资料追溯结果。用户问题在右，模拟回答在左。
- 日汇总、支付结构与数据统计共用同一套模拟数据。选择不同示例日期后，统计和汇报同步使用对应日期的数据。
- 智能体广场：数据、知识、业务三类，共 11 个入口。点击模块进入独立页面；点击侧栏广场返回目录。
- 常用项：中队日志、数据统计、车辆减免查询，与广场中的对应入口一致。
- 模块：选择示例条件后查询或查看预设结果；支持班次筛选、车辆示例编号匹配、知识库原文展开、待核对流水筛选。
- 最近对话只保存在当前页面内存中。新对话不删除旧记录；清空需要确认；关闭并重开演示即重置。

## 能力边界

不是部署完整 ChatRaw Server，不调用模型、MCP、业务 API、文件共享或客户服务器。不提供任意自然语言问答、文件上传、真实识别、实时巡检、文件归档写入、退款、审批或报告下载。表格、OCR、影像及视频模块只呈现清晰标注的预设结果。

模拟知识条目不是现行政策；待核对流水不代表收费损失。缺失月份不填零，模糊字段不猜测。演示内不出现客户地区名称或实际站点身份。内部语言为中文，官网外层沿用已有多语言。

## 接入与验证

通过 `services/case-access/resources.mjs` 的 `digital-toll` 条目登记 `demoPath` 和 `demoEntry`，官网已有案例按钮读取预览描述后接入统一外壳。操作绑定完成后发送 `case-demo-ready`，Escape 在没有内部确认框时发送 `case-demo-close`；不发送高度消息。同源授权网关负责每个资源请求；不新增公开 Worker 路由、外部 API 或独立账号。

运行仓库既有 `npm run verify -- --base=upstream/main`。案例行为由 `tests/browser/demos/digital-toll.mjs` 验证，覆盖主流程、模块筛选、模拟数据一致性、清空确认和关闭重开；公共验收负责访问权限与撤权、桌面和窄屏及外层中英文。

## 素材

`public/icons/` 为 npm 官方 `lucide-static@0.468.0` 中选取的 SVG 图标，未修改图形。对应 ISC 许可保留为 `public/icons/LICENSE`。无客户图片、真实视频或外部 CDN 依赖。字体使用系统字体栈，不复制官网字体子集。
